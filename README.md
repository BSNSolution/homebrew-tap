# BSN Solution — Homebrew tap

```bash
brew install bsnsolution/tap/bsn-palm
bsn-palm setup
```

A fórmula instala só o instalador do **Bsn Palm** (o mesmo `install.sh` público de
https://getpalm.bsnsolution.com.br) e o comando `bsn-palm`. O programa em si é baixado no
`bsn-palm setup`, com a sua licença, por um link temporário — este repositório não tem
código do Bsn Palm.

Atualizar: `bsn-palm update`.
